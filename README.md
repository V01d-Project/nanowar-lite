# 细胞战争 Lite

一个浏览器里就能玩的极简细胞争夺战：圈选自己的细胞，派兵占领别家的细胞，把所有细胞变成自己的颜色就赢。

玩法致敬 Benoit Freslon 的 *Nano War 2*（2011）。本项目代码与美术全部原创，未使用原作的任何素材。

## 玩

打开页面即可，单机对人机 AI。手机竖屏、电脑宽屏都适配。

- 手指画圈 / 鼠标拖框：选中多个自己的细胞
- 点目标细胞：从已选细胞各派出 50% 兵力
- 细胞按各自的成长速度产兵，上限 100
- 占满全图即胜；被 AI 占满即负

## 开发

单文件 `index.html`，无依赖、无构建。改完刷新即可。
